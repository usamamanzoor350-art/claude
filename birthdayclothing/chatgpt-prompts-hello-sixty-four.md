# ChatGPT Image Prompts: "hello SIXTY FOUR · EST. 1962" (8-image set)

**Reference shirt:** black crew-neck tee, white print: script **"hello"**, bold capitals **"SIXTY FOUR"** with a small heart, and **"EST. 1962"** below.

## How to use
1. Open a **new ChatGPT chat** for this shirt.
2. **Attach the shirt photo** (the black "hello SIXTY FOUR" flat lay) to **every** prompt.
3. Paste **one prompt at a time**, in order. Stay in the same chat so the model and style stay consistent.
4. **Check every image** before using it:
   - It says exactly **hello / SIXTY FOUR / EST. 1962**, with no missing or extra letters
   - The heart is there, after "FOUR"
   - Script "hello" and bold capitals look like the original
   - The shirt color is correct
   - If anything is wrong, reply: *"The print is wrong. Copy the design from the attached image exactly, letter for letter: hello / SIXTY FOUR / EST. 1962."*
5. **Reuse for other shirts:** swap the design words, the year and the age of the model (see the bottom of this file).
