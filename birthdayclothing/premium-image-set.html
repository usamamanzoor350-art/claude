Making "tap a color → see 8 images in that color" work in Shopify

Shopify doesn't group a set of images per color on its own; by default it shows every image of every color.

  • Horizon theme: assign images to each color variant in the product admin, then set the product media to carousel in the theme editor.
  • Dawn or other themes: use a variant-images app (for example Rubik Variant Images or NS Color Swatch Variant Images).
  • Name files clearly, e.g. hello-64-black-01-hero.png … hello-64-black-08-colors.png, so assigning them is fast.
  • Image 8 (all colors) can go in every color's set.
